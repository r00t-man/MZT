# Широкие inline-кнопки в Telegram

## Проблема

Telegram схлопывает обычные пробелы (` `) в тексте inline-кнопок. Из-за этого кнопку нельзя «растянуть» пробелами — они просто исчезнут.

**Зачем нужна широкая кнопка?**
Если под кнопкой в полную ширину располагаются две кнопки в ряд, Telegram задаёт ширину всей клавиатуры по самой широкой строке. Если верхняя кнопка узкая — нижние кнопки тоже сожмутся, и текст в них может обрезаться.

---

## Решение: символ U+2800 BRAILLE PATTERN BLANK

Символ `⠀` (U+2800, «Braille Pattern Blank») визуально выглядит как пробел, но **не является пробелом с точки зрения Telegram** — мессенджер не схлопывает его. Это позволяет использовать его как «невидимый» паддинг фиксированной ширины.

### Принцип центрирования

Паддинг должен быть **симметричным** с обеих сторон текста:

```python
PAD = "⠀"  # U+2800 BRAILLE PATTERN BLANK

# ✅ Правильно — текст по центру
button_text = PAD * 11 + "🔄 Обновления" + PAD * 11

# ❌ Неправильно — текст уедет влево
button_text = "🔄 Обновления" + PAD * 22
```

---

## Пример: главное меню бота

```python
PAD = "⠀"  # U+2800 BRAILLE PATTERN BLANK

def kb_main() -> dict:
    return {"inline_keyboard": [
        # Широкие кнопки на всю ширину — задают ширину клавиатуры
        [{"text": PAD * 11 + "🔄 Обновления" + PAD * 11, "callback_data": "updates_menu"}],
        [{"text": PAD * 10 + "📡 Remnawave"  + PAD * 10, "callback_data": "remnawave_menu"}],

        # Двухколоночные кнопки ниже — растянутся до ширины верхних
        [{"text": "🔒 Сертификаты", "callback_data": "certs"},
         {"text": "🐳 Docker",      "callback_data": "docker"}],
        [{"text": "💻 Система",     "callback_data": "sysstat"},
         {"text": "☁️ Cloudflare",  "callback_data": "cf"}],
    ]}
```

В этом примере верхние кнопки с паддингом задают максимальную ширину клавиатуры, и все нижние двухколоночные кнопки занимают ту же ширину — текст в них не обрезается.

---

## Подбор количества символов

Количество `⠀` зависит от длины текста и эмодзи. Универсальной формулы нет — подбирается опытным путём. Практические ориентиры:

| Длина текста кнопки | Паддинг с каждой стороны |
|---|---|
| Короткий (до 10 симв.) | 13–15 |
| Средний (10–20 симв.) | 8–12 |
| Длинный (20+ симв.) | 3–7 |

> **Совет:** эмодзи занимают примерно 2 обычных символа по ширине — учитывайте это при подборе.

---

## Вставка символа U+2800

### Python
```python
PAD = "⠀"
# или скопировать напрямую: ⠀
```

### Проверка в Python
```python
>>> s = "⠀"
>>> hex(ord(s))
'0x2800'
>>> len(s)
1
```

## Ограничения

- Символ невидим, но занимает место — в очень длинных строках может переноситься на новую строку на узких экранах.
- Не злоупотребляйте: несколько десятков символов с одной стороны обычно достаточно.
- Количество паддинга подбирается под конкретный шрифт и устройство — Telegram Desktop и мобильный клиент могут слегка отличаться.
