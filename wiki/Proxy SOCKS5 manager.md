# 🚀 SOCKS5 (Dante) Manager for Telegram

> [!WARNING]
> **Статья может быть неактуальна.** SOCKS5-прокси для Telegram сейчас менее востребован, чем раньше —
> для обхода блокировок практичнее полноценный VPN (см. раздел [🌊 Remnawave](../Remnawave/README.md)).
> Инструкция ниже рабочая, но перед использованием стоит проверить, не появилось ли более актуального
> способа под конкретную задачу.

Удобный Bash-скрипт для быстрой установки и управления **SOCKS5 прокси на Dante** под **Ubuntu** / **Debian**.

Скрипт умеет:

- ⚡ устанавливать и переустанавливать **Dante**
- 👤 создавать основного пользователя `gisproxy`
- 🔐 генерировать случайные пароли в формате `hex`
- ➕ добавлять/🗑️ удалять/♻️ менять пароль пользователям
- 🔎 показывать текущие настройки прокси
- 🔗 генерировать готовые **Telegram-ссылки**
- ✏️ открывать конфиг на редактирование
- 🌐 менять порт прокси
- 🛡️ предлагать открыть порт в **UFW**

---

## 📦 Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/r00t-man/MZT/refs/heads/main/files/Proxy_socks5_dante.sh)
```

> [!NOTE]
> Запускать от `root` или через `sudo -i`.

Или сначала скачать, потом запустить вручную:

```bash
wget -O Proxy_socks5_dante.sh https://raw.githubusercontent.com/r00t-man/MZT/refs/heads/main/files/Proxy_socks5_dante.sh
chmod +x Proxy_socks5_dante.sh
sudo ./Proxy_socks5_dante.sh
```

## 🖥️ Что делает скрипт

После запуска откроется меню управления:

```text
1)  Установить / переустановить SOCKS5 (Dante)
2)  Показать текущие настройки прокси
3)  Добавить нового пользователя
4)  Удалить пользователя
5)  Сменить пароль пользователю
6)  Показать ссылку для выбранного пользователя
7)  Удалить всех пользователей кроме gisproxy
8)  Редактировать /etc/danted.conf
9)  Сменить порт прокси
10) Перезапустить danted
11) Показать статус danted
0)  Выход
```

## ⚙️ Первая установка

После запуска скрипта выбираем `1) Установить / переустановить SOCKS5 (Dante)`. Скрипт предложит
выбрать порт: `8443`/`9443` (✅ рекомендуются), `1194`/`51820` (альтернативные) или свой.

После установки скрипт покажет IP сервера, порт, логин, пароль и готовую ссылку для Telegram:

```text
=== SOCKS5 (Dante) ready ===
Iface   : ens3
IPv4    : 203.0.113.36
Port    : 8443
User    : gisproxy
Pass    : a3f7c9e2b6d1f048e5a9c2b7d4f18e63
Listen  : yes
```

### 🔗 Подключение в Telegram

Скрипт автоматически генерирует ссылку вида:

```text
https://t.me/socks?server=203.0.113.36&port=8443&user=gisproxy&pass=PASSWORD
```

Копируем ссылку → отправляем себе в Telegram → нажимаем на неё → Telegram сам предложит добавить
SOCKS5-прокси.

## 👤 Управление пользователями

- `3) Добавить нового пользователя` — создаёт нового пользователя Linux, генерирует случайный пароль,
  показывает готовую ссылку Telegram
- `5) Сменить пароль пользователю` — генерирует новый пароль, обновляет, показывает новую ссылку
- `4) Удалить пользователя` — удаляет одного пользователя
- `7) Удалить всех пользователей кроме gisproxy`

## 🌐 Смена порта и ручное редактирование

- `9) Сменить порт прокси` — один из рекомендуемых или свой вручную
- `8) Редактировать /etc/danted.conf` — основной конфиг лежит в `/etc/danted.conf`; после ручной
  правки выполните `10) Перезапустить danted`

## 📊 Просмотр текущих настроек

`2) Показать текущие настройки прокси` — статус сервиса, интерфейс, IP, порт, список пользователей,
пароли, Telegram-ссылки.

---

## 🧾 Где хранятся данные

| Файл | Назначение |
|---|---|
| `/etc/danted.conf` | конфиг Dante |
| `/etc/danted.conf_bak` | резервная копия конфига |
| `/root/.dante_socks_users` | локальное хранилище пользователей и паролей (только добавленные этим скриптом) |

## 🛡️ Firewall / UFW

Если на сервере активен **UFW**, скрипт предложит автоматически открыть выбранный порт для `TCP`/`UDP`.
Если отказались при установке — открыть вручную:

```bash
ufw allow 8443/tcp
ufw allow 8443/udp
```

Заменяйте `8443` на свой выбранный порт.

## ✅ Проверка работы

```bash
systemctl status danted --no-pager -l
ss -tulpn | grep danted
journalctl -u danted -n 100 --no-pager
```

## 🧰 Требования

Ubuntu/Debian, root-доступ, установленный `curl` или `wget`.

## 💡 Рекомендации по портам

Обычно лучше использовать `8443`/`9443`, альтернативы — `1194`/`51820`. Если порт занят, проверить это
можно так: `ss -tulpn | grep 8443`.

## 📌 Примечания

- основной пользователь по умолчанию: `gisproxy`
- пароли генерируются автоматически
- SOCKS5 в Telegram подключается через готовую ссылку
