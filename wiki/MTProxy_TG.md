# 🚀 MTProxy для Telegram + Каскадная схема (RU → EU)

📡 **Эстония указана как пример.** Подойдёт **любой сервер за пределами России**.

Для наглядности используем такие IP:

| Сервер | IP |
|------|------|
| 🇪🇪 Эстония (основной MTProxy) | `11.111.111.11` |
| 🇷🇺 Москва (каскад) | `22.222.222.22` |

---

## ⚡ Установка и запуск MTProxy (в один клик)

Скрипт автоматически устанавливает **MTProxy**, открывает порт, генерирует **secret** и выводит
**готовую ссылку подключения**:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/r00t-man/MZT/refs/heads/main/files/tg_mtproxy.sh)
```

После запуска появится **интерактивное меню** управления прокси.

### 📥 Альтернативный способ (скачать скрипт)

```bash
wget https://raw.githubusercontent.com/r00t-man/MZT/refs/heads/main/files/tg_mtproxy.sh
chmod +x tg_mtproxy.sh
./tg_mtproxy.sh
```

---

## 🌍 Поднимаем MTProxy на зарубежном сервере

📍 В нашем примере это сервер Эстонии, IP `11.111.111.11`.

Рекомендуемые порты:

| Порт      | Когда использовать    |
| --------- | --------------------- |
| **443**   | стандартный вариант   |
| **1194**  | если 443 занят VPN    |
| **51820** | если 443 занят сайтом |

Например используем **1194**.

### 📊 Пример данных прокси

```text
IP:     11.111.111.11
Port:   1194
Secret: eef1fcce68d332df9d61ff143c2bb0a5c66578616d706c652e636f6d
```

### 🔗 Ссылка подключения

```text
tg://proxy?server=11.111.111.11&port=1194&secret=eef1fcce68d332df9d61ff143c2bb0a5c66578616d706c652e636f6d
```

### ✅ Проверяем прямое подключение

1. Отправляем ссылку себе в **Telegram**
2. Нажимаем на неё
3. Telegram автоматически предложит **добавить прокси**

Если прокси работает стабильно — на этом можно остановиться и пользоваться им.

## 🔀 Настройка каскадного MTProxy

Каскад полезен, если есть сервер **в России**, прямой прокси работает нестабильно или требуется обход
некоторых блокировок:

```
Telegram
   ↓
🇷🇺 Москва
   ↓
🇪🇪 Эстония
   ↓
Telegram сеть
```

На **Московском сервере** запускаем **тот же скрипт**:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/r00t-man/MZT/refs/heads/main/files/tg_mtproxy.sh)
```

В меню выбираем `3) Настроить правило MTProxy Kaskad`, указываем IP сервера назначения (`11.111.111.11`)
и порт (`1194`).

### 🔗 Итоговая каскадная ссылка

Меняем IP в ссылке подключения на Московский сервер:

Было:
```text
tg://proxy?server=11.111.111.11&port=1194&secret=SECRET
```

Станет:
```text
tg://proxy?server=22.222.222.22&port=1194&secret=eef1fcce68d332df9d61ff143c2bb0a5c66578616d706c652e636f6d
```

### 📲 Подключение

Отправляем ссылку себе в Telegram → нажимаем на неё → Telegram проверит соединение → прокси
добавится в настройки.

### 🧠 Итоговая схема

```
Telegram клиент
        │
        ▼
🇷🇺 Москва (22.222.222.22)
        │
        ▼
🇪🇪 Эстония (11.111.111.11)
        │
        ▼
Telegram сеть
```

## 💡 Полезные советы

- Используйте **443**, если порт свободен
- Если сервер уже использует **VPN** — используйте `1194`
- Если сервер использует **WireGuard** — используйте `51820`

## 🔧 Управление прокси

Скрипт позволяет:

| Пункт | Возможность                 |
| ----- | ---------------------------- |
| 1     | Установить MTProxy          |
| 2     | Показать данные подключения |
| 3     | Настроить каскад            |
| 4     | Перезапустить прокси        |
| 5     | Остановить прокси           |
| 0     | Выход                       |

---

💬 **MTProxy + каскад — один из самых стабильных способов обхода блокировок Telegram.**

> [!NOTE]
> Разные операторы связи, домашний интернет и Wi-Fi сети могут по-разному работать с прокси. Поэтому у
> одних пользователей могут работать все серверы, а у других — только часть из них. Это нормально и
> зависит от интернет-провайдера, мобильного оператора, типа подключения.
>
> Также бывает, что Telegram показывает прокси как «недоступный». В этом случае его всё равно можно
> добавить — иногда так работает проверка Telegram или фильтрация со стороны оператора, и после
> добавления прокси начинает работать нормально.
