# Каталог уроков (русский перевод заголовков) — Claude Code: Everything You Need to Know

Краткий ориентир по содержанию репозитория — переведённые заголовки и однострочная суть каждого урока, не полный перевод. Полный текст уроков — в оригинальных файлах на английском (`docs/...`), это только карта, что где искать.

## Beginner (начальный уровень)

- **Установка, вход и осмотр** (`docs/beginner/01-install-and-look-around.md`) — Урок о том, как установить Claude Code, войти, запустить в репозитории и определить версию, модель и аккаунт сессии.
- **Выбор, кто что одобряет: режимы разрешений и режим плана** (`docs/beginner/02-permission-modes-and-plan-mode.md`) — Урок о выборе режима разрешений для задачи, переключении режимов во время сессии и использовании режима плана для одобрения плана.
- **Ваше первое изменение: от запроса до коммита** (`docs/beginner/03-first-change.md`) — Урок о проведении одного изменения от запроса до коммита: исследование, план, реализация, тестирование, просмотр diff, исправление и коммит.
- **Удержание сессии в нужном русле** (`docs/beginner/04-keep-a-session-on-track.md`) — Урок о том, как следить за заполненностью контекста, очищать или сжимать его, откатывать изменения и возобновлять предыдущий разговор.
- **Память проекта с CLAUDE.md** (`docs/beginner/05-project-memory.md`) — Урок о создании файла CLAUDE.md проекта и демонстрации того, что новая сессия следует ему.
- **Начальный уровень** (`docs/beginner/README.md`) — Обзор начального уровня: одна сессия, одно изменение — установка, разрешения, проведение изменения, удержание сессии и память проекта.
- **Начальный capstone: исправьте зарегистрированный баг, от плана до коммита** (`docs/beginner/capstone.md`) — Итоговое задание начального уровня: исправление бага от плана до коммита без готового примера.
- **Учитесь у самого Claude Code** (`docs/beginner/electives/built-in-teachers.md`) — Электив об использовании встроенных средств обучения: `/powerup`, стилей вывода Learning и Explanatory, а также гайда по функциям.
- **Использование Claude Code в редакторе** (`docs/beginner/electives/ide-extensions.md`) — Электив о запуске Claude Code внутри VS Code или JetBrains IDE, указании на нужные строки и просмотре правок в редакторе.
- **Дайте Claude скриншот** (`docs/beginner/electives/screenshots-and-images.md`) — Электив о добавлении скриншота или изображения в разговор и получении изменения на основе увиденного.

## Intermediate (средний уровень)

- **Превратите повторяющийся workflow в skill** (`docs/intermediate/01-first-skill.md`) — Урок о превращении повторяющегося workflow в проектный skill, который запускается по имени и загружается автоматически при совпадении запроса.
- **Организация памяти проекта и просмотр загруженного** (`docs/intermediate/02-organize-memory.md`) — Урок о разделении инструкций проекта на импорты и правила с областью действия, а также о том, как узнать, какие файлы инструкций загрузились.
- **Выбор модели и уровня усилий** (`docs/intermediate/03-model-and-effort.md`) — Урок о выборе модели и уровня усилий для задачи, установке их для сессии или отдельного skill и определении необходимости повышения по неверному результату.
- **Разрешения, области настроек и песочница** (`docs/intermediate/04-permissions-and-sandbox.md`) — Урок о размещении правил разрешений в файле настроек с подходящей областью, просмотре действующих правил и включении песочницы.
- **Обеспечение правила с помощью hook** (`docs/intermediate/05-hooks.md`) — Урок о добавлении hook, который обеспечивает соблюдение правила при каждом редактировании файла Claude, и демонстрации его срабатывания.
- **Делегирование пользовательскому субагенту** (`docs/intermediate/06-subagents.md`) — Урок о написании субагента, имеющего только необходимые для задачи инструменты, и делегировании ему работы.
- **Подключение инструмента через MCP** (`docs/intermediate/07-mcp.md`) — Урок о подключении MCP-сервера для себя и предоставлении его всем в проекте на уровне проекта с закреплением версии.
- **Установка и управление плагинами** (`docs/intermediate/08-plugins.md`) — Урок об установке и управлении плагинами, объединяющими skills, агентов, hooks и MCP-серверы.
- **Средний уровень** (`docs/intermediate/README.md`) — Обзор среднего уровня: настройка Claude Code под свой проект — skills, память проекта, модель и усилия, разрешения и песочница, hooks, субагенты, MCP-серверы и плагины.
- **Средний capstone: подготовьте репозиторий для нового коллеги** (`docs/intermediate/capstone.md`) — Итоговое задание среднего уровня: подготовка репозитория для нового члена команды без готового примера.
- **Проверка изменений UI в браузере с Claude in Chrome** (`docs/intermediate/electives/claude-in-chrome.md`) — Электив о подключении Claude Code к браузеру и проверке изменённой страницы: консоль, отображение и скриншот.
- **Быстрый режим** (`docs/intermediate/electives/fast-mode.md`) — Электив о быстром режиме — функции в research preview для ускорения ответов.
- **Паттерны skill: живые данные, вспомогательные файлы и собственный контекст** (`docs/intermediate/electives/skill-patterns.md`) — Электив о написании skill, который подтягивает живые данные в промпт, хранит длинные справочные материалы отдельно и имеет собственный контекст.
- **Настройка строки статуса** (`docs/intermediate/electives/status-line.md`) — Электив о создании собственной строки статуса для Claude Code с помощью скрипта, показывающего модель, папку и заполненность контекстного окна.

## Advanced (продвинутый уровень)

- **Параллельные сессии с worktrees** (`docs/advanced/01-parallel-sessions.md`) — Урок о том, как запускать две сессии Claude Code одновременно в разных git worktrees и объединять их работу в одну ветку.
- **Выбор паттерна оркестрации** (`docs/advanced/02-orchestration-patterns.md`) — Урок о выборе между основной беседой, субагентами, динамическим workflow и командой агентов в зависимости от задачи и затрат.
- **Запуск и сохранение динамического workflow** (`docs/advanced/03-dynamic-workflows.md`) — Урок о том, как попросить Claude написать динамический workflow для задачи, распределённой по многим файлам, и сохранить его.
- **Скриптинг Claude Code с помощью `claude -p`** (`docs/advanced/04-headless.md`) — Урок о написании скрипта, который запускает Claude Code без участия человека, читает JSON-результат и код выхода, ограничивая доступные инструменты.
- **GitHub Actions** (`docs/advanced/05-github-actions.md`) — Урок о запуске Claude Code в автономном режиме в workflow GitHub Actions с чтением учётных данных из секрета репозитория и ограничениями.
- **Общий доступ к настройке для команды** (`docs/advanced/06-share-your-setup.md`) — Урок о том, как поделиться настройкой Claude Code с командой: закоммитить общие настройки, исключить личные файлы из git и предоставить плагин.
- **Ограничения для автономных запусков** (`docs/advanced/07-bounded-runs.md`) — Урок о том, как ограничить автономный запуск `claude -p` с помощью минимальных привилегий, песочницы и других средств.
- **Продвинутый уровень** (`docs/advanced/README.md`) — Обзор продвинутого уровня: параллельные сессии, оркестрация, автономные запуски в скриптах и CI, общая настройка команды и безопасные ограничения.
- **За пределами этого гайда** (`docs/advanced/beyond-this-guide.md`) — Куда двигаться после завершения продвинутого уровня: создание собственных агентов и MCP-серверов, запуск Claude Code для организации и внедрение в команде.
- **Продвинутый capstone: добавьте CI-ревью для команды** (`docs/advanced/capstone.md`) — Итоговое задание, объединяющее весь продвинутый уровень: настройка CI-ревью, которым может пользоваться команда.
- **Команды агентов** (`docs/advanced/electives/agent-teams.md`) — Электив о командах агентов — экспериментальной функции, отключённой по умолчанию, для оркестрации нескольких сессий Claude Code.
- **Представление агентов** (`docs/advanced/electives/agent-view.md`) — Электив о представлении агентов — функции в стадии research preview для управления несколькими агентами.
- **Dev-контейнеры** (`docs/advanced/electives/dev-containers.md`) — Электив о запуске Claude Code внутри dev-контейнера, сохранении входа при пересборке и автономной работе за файрволом.
- **`/goal`, `/loop` и routines** (`docs/advanced/electives/goal-loop-routines.md`) — Электив о routines — функции в research preview для автоматизации работы с помощью целей и циклов.
- **Тестирование и публикация плагина** (`docs/advanced/electives/publish-a-plugin.md`) — Электив о проверке файлов плагина с помощью `claude plugin validate`, оценке изменений с `claude plugin eval` и публикации.

## Topics (отдельные темы)

- **Темы** (`docs/topics/README.md`) — Каждая тематическая страница перечисляет уроки по уровням, элективы, справочную страницу и официальную документацию; страницы только ссылаются, не обучают.
- **Автоматизация** (`docs/topics/automation.md`) — Тема о запуске Claude Code без человека: скрипты, CI и расписания.
- **Hooks** (`docs/topics/hooks.md`) — Тема о командах, выполняемых в фиксированные моменты сессии, чтобы правило соблюдалось без опоры на память Claude.
- **MCP** (`docs/topics/mcp.md`) — Тема о подключении Claude Code к внешним инструментам и данным с помощью Model Context Protocol.
- **Память и контекст** (`docs/topics/memory-and-context.md`) — Тема о том, что Claude Code знает в начале сессии и что заполняет его контекст по мере работы.
- **Модели, усилия и стоимость** (`docs/topics/models-effort-and-cost.md`) — Тема о том, какая модель и уровень усилий нужны задаче и сколько стоит сессия.
- **Разрешения и безопасность** (`docs/topics/permissions-and-safety.md`) — Тема о том, что Claude Code может делать без спроса и как уберечь его от нежелательных действий.
- **Плагины** (`docs/topics/plugins.md`) — Тема о пакетах skills, агентов, hooks и MCP-серверов, устанавливаемых из маркетплейса.
- **Skills** (`docs/topics/skills.md`) — Тема об упакованных инструкциях, которые запускаются по имени или загружаются при соответствии.
- **Субагенты и параллельная работа** (`docs/topics/subagents-and-parallel-work.md`) — Тема о способах разделения работы между контекстами и сессиями: субагенты, worktrees, динамические workflow и команды агентов.
