# Учитесь у самого Claude Code

<sub>**Начинающий** · Электив · около 20 минут · Требуется: [Установка, вход и осмотр](../01-install-and-look-around.md) · Проверено с Claude Code v2.1.292 (stable) 2026-10-15</sub>

## Цель

К концу этого Электива вы сможете использовать встроенные обучающие средства Claude Code: `/powerup`, стили вывода Learning и Explanatory, а также руководство по его собственным функциям.

## Вам понадобится

- Ваша копия практического шаблона без незакоммиченных изменений.
- Использование: лёгкое.

## Идея

Claude Code может обучать вас во время работы. Встроены три средства:

- **`/powerup`** запускает быстрые интерактивные уроки по функциям Claude Code с анимированными демонстрациями ([Команды](https://code.claude.com/docs/en/commands)).
- **Стили вывода** меняют то, как Claude отвечает ([Стили вывода](https://code.claude.com/docs/en/output-styles)). В стиле **Explanatory** Claude добавляет короткие блоки `Insight`, объясняющие выбор, стоящий за его кодом. Стиль **Learning** добавляет те же блоки, а также оставляет несколько строк реальных решений для вас, чтобы вы их написали.
- **Руководство по Claude Code**: `claude-code-guide` — это встроенный помощник для вопросов о собственных функциях Claude Code ([Создание пользовательских субагентов](https://code.claude.com/docs/en/sub-agents)). Claude обычно вызывает его сам, когда вы спрашиваете о Claude Code, а когда вы называете его в своём запросе, Claude, как правило, передаёт вопрос ему ([Явный вызов субагентов](https://code.claude.com/docs/en/sub-agents#invoke-subagents-explicitly)).

Зачем писать часть кода самостоятельно? В исследовании Anthropic разработчики, изучавшие новую библиотеку с помощью ИИ-ассистента, в среднем набирали меньше баллов в тесте по ней, чем разработчики, писавшие код вручную. Те, кто набрал высокие баллы, использовали ассистента для вопросов и получения объяснений, а не только для генерации кода ([Как помощь ИИ влияет на формирование навыков программирования](https://www.anthropic.com/research/AI-assistance-coding-skills)). Стиль Learning прививает эту привычку.

## Практический пример

1. Запустите `claude` в своей практической копии и выполните `/powerup`. Выберите урок, попробуйте то, что он показывает, и следуйте подсказкам на экране. Урок считается завершённым, когда вы нажмёте `Enter` на его карточке (`Enter to mark done`). Если урок `/powerup` называет режим `default`, это ручной режим ([Выбор режима разрешений](https://code.claude.com/docs/en/permission-modes)), который рассматривается в [уроке 2](../02-permission-modes-and-plan-mode.md).
2. Переключите стиль вывода:

   ```text
   /output-style learning
   ```

   Claude Code сохраняет выбор в `.claude/settings.local.json` в этом проекте, поэтому каждая сессия, начатая здесь, сохраняет этот стиль, пока вы не выполните `/output-style default`. Ваш ход заканчивается этим шагом; если вы остановитесь до него, выполните его самостоятельно.
3. Попросите внести небольшое изменение, которое оставляет решение за вами:

   ```text
   Добавьте функцию в src/links.js, которая подсчитывает внешние ссылки на странице, с тестом. Решение о повторяющихся ссылках оставьте мне.
   ```

   Claude объясняет свой выбор в блоках `Insight`, хотя и не в каждом ответе. Когда он доходит до этого решения, он добавляет комментарий `TODO(human)` в файл и останавливается с запросом `Learn by Doing`, в котором говорится, что написать ([Стили вывода](https://code.claude.com/docs/en/output-styles#learning)). Откройте файл, который он называет, в своём редакторе, напишите свои строки у комментария `TODO(human)`, сохраните и скажите Claude, что вы закончили. Claude прокомментирует ваш код и завершит задачу; если он не запустит тесты, попросите его об этом. Стиль — это инструкция, а не гарантия: если Claude напишет весь код сам, попросите его оставить решение о повторяющихся ссылках вам.
4. Когда тесты пройдут, отложите изменение, чтобы последующие уроки начинались с чистого листа. Откройте второй терминал в той же папке и выполните:

   ```bash
   git stash push --include-untracked -m b-teachers
   ```

5. Вернувшись в Claude Code, спросите о самом Claude Code и назовите помощника, чтобы Claude передал вопрос ему ([Явный вызов субагентов](https://code.claude.com/docs/en/sub-agents#invoke-subagents-explicitly)):

   ```text
   Используйте агента claude-code-guide: как мне создать собственную slash-команду в Claude Code?
   ```

   Когда Claude передаёт вопрос, в транскрипте появляется строка `claude-code-guide(...)` с кратким описанием задачи в скобках. Если такой строки нет, Claude ответил без помощника: отправьте запрос снова. Ваша формулировка может отличаться, но ответ должен указать вам на навыки, файл `SKILL.md` в `.claude/skills/` ([Расширение Claude с помощью навыков](https://code.claude.com/docs/en/skills)). Он также может упомянуть более старую папку `.claude/commands/`, которая всё ещё работает.

## Ваш ход

1. Выполните `/powerup` и завершите ещё один урок.
2. Переключитесь на стиль Explanatory с помощью `/output-style explanatory`, попросите Claude объяснить `src/check-links.js` и прочитайте его блоки `Insight`. Затем во втором терминале сохраните настройку для проверки:

   ```bash
   cp .claude/settings.local.json .practice/b-teachers-style.json
   ```

3. Спросите `claude-code-guide` о функции Claude Code, которую вы ещё не использовали: начните запрос с `Use the claude-code-guide agent:` и найдите его строку в транскрипте. Если вы уже спрашивали помощника ранее в этой сессии, Claude может отправить вопрос тому же помощнику: тогда в транскрипте будет `Resuming agent` вместо новой строки `claude-code-guide(...)`, и это тоже засчитывается.
4. Когда закончите, переключитесь обратно с помощью `/output-style default`.

## Проверка

В этом Элективе нет `npm run check`: отметьте каждый пункт самостоятельно. Вы закончили, когда все следующие утверждения верны:

- [ ] `.practice/b-teachers-style.json`, сохранённый на шаге 2 раздела «Ваш ход», содержит запись `outputStyle` для стиля Explanatory. Проверьте с помощью `cat .practice/b-teachers-style.json`.
- [ ] Самопроверка (не тестируется): вы завершили два урока `/powerup`.

Если файл отсутствует или в нём указан другой стиль, выполните `/output-style explanatory` в Claude Code, повторите команду `cp` во втором терминале, затем выполните `/output-style default`.
