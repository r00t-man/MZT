# За пределами этого руководства

<sub>**Продвинутый уровень** · Проверено с Claude Code v2.1.292 (stable) 2026-10-15</sub>

Куда двигаться после завершения продвинутого раздела. Руководство обучает использованию Claude Code одним разработчиком, в одиночку или в команде. Создание собственных агентов и MCP-серверов, запуск Claude Code для целой организации и внедрение его в команде — это отдельные задачи со своей официальной документацией, поэтому данная страница лишь ссылается на них, а не обучает им.

Все материалы опубликованы Anthropic, за исключением страниц проекта MCP на modelcontextprotocol.io.

Списки проверены по панели навигации 2026-10-09.

## Создание собственных агентов

Чтобы встроить цикл агента Claude Code в ваше собственное приложение:

- [Обзор Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview): инструменты, цикл агента и управление контекстом, лежащие в основе Claude Code, в виде библиотеки для Python или TypeScript. Первая таблица сравнивает его с другими инструментами Claude.
- [Быстрый старт Agent SDK](https://code.claude.com/docs/en/agent-sdk/quickstart): создание агента, который находит и исправляет ошибки в существующем коде.
- [Введение в Claude](https://platform.claude.com/docs/en/intro): API Claude, с путём от первого вызова API до рабочей интеграции.

Для управления тем же циклом агента из языка, отличного от Python или TypeScript, документация предлагает запускать CLI как подпроцесс с флагами `-p` и `--output-format json` ([Обзор Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview#compare-the-agent-sdk-to-other-claude-tools)), как это делает скрипт в [Скриптование Claude Code с помощью `claude -p`](04-headless.md).

Продукт или сервис, созданный на основе Agent SDK, должен использовать аутентификацию по API-ключу через Claude Console или поддерживаемого облачного провайдера ([Правовые вопросы и соответствие требованиям](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)). Без предварительного одобрения Anthropic не разрешает сторонним разработчикам предлагать вход через claude.ai для своих продуктов ([Обзор Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview#get-started)).

Пока вы пишете код, вызывающий API Claude, встроенный навык `/claude-api` загружает справочные материалы по API Claude для языка вашего проекта, и Claude также загружает его самостоятельно, когда ваш код импортирует `anthropic` или `@anthropic-ai/sdk` ([Навыки](https://code.claude.com/docs/en/skills#work-on-claude-api-projects)).

## Создание MCP-серверов

В разделе [Подключение инструмента с помощью MCP](../intermediate/07-mcp.md) использовался сервер, написанный кем-то другим. Чтобы написать свой собственный:

- [Поиск и создание MCP-серверов](https://code.claude.com/docs/en/mcp#find-and-build-mcp-servers): куда документация Claude Code направляет разработчиков серверов, для основ протокола и для аутентификации коннекторов, тестирования и отправки в каталог Anthropic.
- [Создание MCP-сервера](https://modelcontextprotocol.io/docs/develop/build-server) (Поставщик: проект MCP): собственный учебник проекта MCP и его [SDK](https://modelcontextprotocol.io/docs/sdk) для создания серверов и клиентов.
- [Введение в Model Context Protocol](https://academy.claude.com/courses/introduction-to-model-context-protocol): курс Claude Academy по созданию серверов и клиентов с нуля с помощью Python SDK.
- [Model Context Protocol: Продвинутые темы](https://academy.claude.com/courses/model-context-protocol-advanced-topics): курс Claude Academy по сэмплированию, уведомлениям и корням.

## Запуск Claude Code для организации

В разделе [Поделитесь своей настройкой с командой](06-share-your-setup.md) настройка фиксируется в репозитории, с которым работает ваша команда. Организация также устанавливает политики, вход в систему, сетевой доступ и отчётность для каждой машины:

- [Настройка Claude Code для вашей организации](https://code.claude.com/docs/en/admin-setup): карта решений Anthropic для администраторов и отправная точка. Охватывает поставщиков API, управляемые настройки, применение политик, мониторинг использования и обработку данных, а также указывает, где настраиваются SSO и назначение мест.
- [Развёртывание управляемых настроек](https://code.claude.com/docs/en/managed-settings) для доставки настроек вашей организации на машину каждого разработчика в каждой операционной системе и [Настройка настроек, управляемых сервером](https://code.claude.com/docs/en/server-managed-settings) для доставки их из консоли claude.ai без управления устройствами.
- [Аутентификация](https://code.claude.com/docs/en/authentication#set-up-team-authentication) для способов настройки доступа к Claude Code командой или организацией и [Обзор корпоративного развёртывания](https://code.claude.com/docs/en/third-party-integrations), который помогает выбрать между развёртыванием через Anthropic и через облачного провайдера.
- [Корпоративная сетевая конфигурация](https://code.claude.com/docs/en/network-config) для прокси-серверов, пользовательских центров сертификации и mTLS, а также [Запуск Claude Code через шлюз](https://code.claude.com/docs/en/gateways) для централизованных учётных данных, отслеживания использования и контроля затрат.
- [Мониторинг](https://code.claude.com/docs/en/monitoring-usage) для экспорта данных об использовании, затратах и активности инструментов через OpenTelemetry и [Отслеживание использования командой с помощью аналитики](https://code.claude.com/docs/en/analytics) — панель использования и внедрения.
- [Использование данных](https://code.claude.com/docs/en/data-usage): политики обучения и хранения данных Anthropic, а также куда отправляются данные сеанса.

Если ваша организация развёртывает управляемые настройки, настройка из урока может не применяться на рабочей машине или на любой машине, где вы входите с рабочей учётной записью: никакие пользовательские, проектные, локальные значения или значения `--settings` не переопределяют их, за исключением нескольких чувствительных к безопасности исключений, где более строгое значение с более низкого уровня всё ещё учитывается ([Развёртывание управляемых настроек](https://code.claude.com/docs/en/managed-settings), [Настройка настроек, управляемых сервером](https://code.claude.com/docs/en/server-managed-settings#platform-availability)). Когда разработчики подключаются через шлюз с учётными данными шлюза, использование оплачивается с учётной записи провайдера организации по тарифам API, а их подписки claude.ai не используются и не оплачиваются ([Подписки и шлюзы](https://code.claude.com/docs/en/gateways#subscriptions-and-gateways)).

## Внедрение в команде

Когда настройка готова, эти материалы помогут людям её освоить:

- [Набор для чемпиона](https://code.claude.com/docs/en/champion-kit): для инженера, уже использующего Claude Code, который хочет помочь своей команде внедрить его.
- [Набор для коммуникаций](https://code.claude.com/docs/en/communications-kit): объявления о запуске, сообщения для капельных кампаний и ответы на часто задаваемые вопросы для администраторов и руководителей инженерных команд, внедряющих Claude Code.
- [Пособие по AI-native SDLC](https://academy.claude.com/courses/ai-native-sdlc-playbook): курс Claude Academy для руководителей инженерных, платформенных и служб безопасности, чья организация уже использует Claude Code.
- [Управление AI-native инженерной организацией](https://claude.com/resources/articles/running-an-ai-native-engineering-org): как изменились процессы и структура команды Claude Code, когда агентное кодирование стало её стандартным способом работы.
