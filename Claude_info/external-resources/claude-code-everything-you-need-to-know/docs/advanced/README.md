# Продвинутый уровень

<sub>**Продвинутый уровень** · около 3 часов 20 минут, плюс время выполнения · Проверено с Claude Code v2.1.292 (stable) 2026-10-15</sub>

За пределами одной сессии: параллельные сессии, оркестрация, автономные запуски в скриптах и CI, общая для команды настройка и ограничения, которые делают автономный запуск безопасным.

## Вы готовы к этому уровню, если можете

- [ ] Написать проектный skill, который запускается по имени и загружается самостоятельно, когда он применим.
- [ ] Написать hook, который обеспечивает соблюдение правила, и показать, как он срабатывает.
- [ ] Делегировать задачу пользовательскому subagent с ограниченным набором инструментов.
- [ ] Добавить MCP-сервер на уровне проекта и установить плагин из маркетплейса Anthropic.
- [ ] Разместить правила разрешений в нужной области видимости, включить песочницу и выбрать модель и уровень усилий для задачи.
- [ ] Организовать память проекта и выяснить, что загрузилось, когда инструкция не была выполнена.

## Практика

Практикуйтесь в собственном репозитории и запускайте каждую проверку из своей копии [шаблона для практики](https://github.com/wesammustafa/claude-code-practice) командой `npm run check -- <lesson-id> --dir <your repo>`. Урок по GitHub Actions и capstone — исключения: они выполняются в отдельной копии шаблона, которую вы затем удаляете, чтобы не осталось ни workflow, ни секретов.

Копия, сделанная вами для более раннего уровня, может не содержать проверок продвинутого уровня: `npm run check` тогда не покажет уроки с префиксом `a-`. Перенесите их из шаблона в свою копию:

```bash
git fetch https://github.com/wesammustafa/claude-code-practice main
git checkout FETCH_HEAD -- checks capstone
git commit -m "Add the Advanced checks"
```

## Capstone

[Добавьте CI-ревью, которым может пользоваться ваша команда](capstone.md): в новой копии шаблона две параллельные сессии в worktrees, ограниченный скрипт ревью `claude -p`, командный маркетплейс, сохранённый динамический workflow и workflow ревью pull request с ограничениями. Затем удалите workflow, секрет и, при наличии API-ключа, сам ключ.

## К концу этого уровня вы сможете

- [ ] Запускать параллельные сессии в worktrees и объединять их результаты.
- [ ] Выбирать между subagent, workflow или командой в зависимости от потребностей и стоимости, а также запускать динамический workflow.
- [ ] Писать скрипт `claude -p` и workflow GitHub Actions.
- [ ] Делиться настройкой как зафиксированной конфигурацией и плагином командного маркетплейса.
- [ ] Ограничивать автономный запуск с помощью принципа наименьших привилегий, песочницы, лимитов на ходы или расходы, контрольной точки ревью и оценки стоимости.
