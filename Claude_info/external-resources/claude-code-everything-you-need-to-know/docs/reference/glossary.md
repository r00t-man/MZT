# Глоссарий

<sub>Проверено на Claude Code v2.1.292 (stable) 2026-10-15</sub>

Слова, которые это руководство использует для своих собственных частей. Для терминов Claude Code, таких как hooks, subagents или compaction, смотрите официальный [Глоссарий](https://code.claude.com/docs/en/glossary).

- **Level:** насколько далеко вы продвинулись: Beginner, Intermediate или Advanced. Beginner охватывает одну сессию и одно изменение, Intermediate — настройку одного разработчика, а Advanced — работу за пределами одной сессии.
- **Lesson:** страница, которая продвигает вас на один шаг к Exit уровня, заставляя вас что-то сделать и проверить это. Каждый урок принадлежит одному уровню и имеет одно место в его порядке.
- **Elective:** необязательный урок вне основного пути уровня. Ничто в Exit уровня не зависит от него.
- **Capstone:** задача, которая завершает уровень и проверяет его Exit за один раз, со своей собственной проверкой.
- **Check:** последняя часть урока: наблюдаемое состояние, такое как файлы, история git, коды выхода или настройки, которое показывает, что ваше упражнение сработало. Это никогда не зависит от того, как Claude формулирует ответ.
- **Exit:** список вещей, которые вы можете делать без посторонней помощи в конце уровня. Exit каждого уровня — это список следующего уровня «Вы готовы к этому уровню, если можете».
