# Темы

<sub>Проверено на Claude Code v2.1.292 (stable) 2026-10-15</sub>

Каждая страница темы перечисляет свои уроки в порядке уровня, свои факультативы, справочную страницу и официальную документацию. Страницы тем содержат ссылки; они не обучают.

- [Память и контекст](memory-and-context.md): что Claude Code знает в начале сессии и что заполняет его контекст по мере работы.
- [Разрешения и безопасность](permissions-and-safety.md): что Claude Code может делать без запроса и как держать его подальше от того, к чему он не должен прикасаться.
- [Навыки](skills.md): упакованные инструкции, которые запускаются по имени или загружаются, когда они применимы.
- [Хуки](hooks.md): команды, которые выполняются в фиксированных точках сессии, так что правило соблюдается без необходимости Claude помнить о нём.
- [Субагенты и параллельная работа](subagents-and-parallel-work.md): способы разделения работы между контекстами и сессиями: субагенты, рабочие деревья, динамические рабочие процессы и команды агентов.
- [MCP](mcp.md): подключение Claude Code к внешним инструментам и данным с помощью Model Context Protocol.
- [Плагины](plugins.md): наборы навыков, агентов, хуков и серверов MCP, которые вы устанавливаете из маркетплейса.
- [Автоматизация](automation.md): запуск Claude Code без человека за клавиатурой: скрипты, CI и расписания.
- [Модели, усилия и стоимость](models-effort-and-cost.md): какая модель и уровень усилий нужны задаче и сколько стоит сессия.
