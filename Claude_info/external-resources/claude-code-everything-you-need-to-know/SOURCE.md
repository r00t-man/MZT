# Источник

Оригинал: https://github.com/wesammustafa/Claude-Code-Everything-You-Need-to-Know

Независимый (не от Anthropic) обучающий гайд по Claude Code — 3 уровня
(beginner/intermediate/advanced), 61 урок с практическими проверками. Лицензия — MIT (см.
`LICENSE` в этой папке).

**Переведено полностью:** `README.md`, все 61 файл `docs/**/*.md`, `CHANGELOG.md`,
`CONTRIBUTING.md`, `SECURITY.md`, `examples/README.md`. Код-блоки, команды, пути файлов и URL
не переводились — только прозаический текст. Технические термины (Claude Code, CLAUDE.md, MCP,
skill, subagent, hook, slash command и подобные) оставлены латиницей по той же причине, что и
в остальной базе знаний — это общепринятые термины, калька только мешает.

**Скопировано без перевода (код/конфиги, не проза):** `examples/**` — реальные файлы примеров
(`dot-claude/`, `test.sh`, `*.json` и т.п.), на которые ссылаются уроки. Переводить код не имеет
смысла.

**Не включено:** `assets/` (картинки/шрифты маскота — ссылки в переводе ведут на оригинал через
`raw.githubusercontent.com`, см. ниже), `mcp-servers/`, `specialized-agents/`, `.claude/`,
`.github/` — служебные файлы самого репозитория-оригинала (его собственная настройка Claude Code,
шаблоны issue/PR), не часть обучающего контента. Ссылки на них из текста ведут на оригинал на
GitHub.

**Известные особенности перевода:**
- Несколько markdown-уроков содержат учебные ПРИМЕРЫ синтаксиса ссылок внутри обратных кавычек
  (например `` [setup](setup.md "Setup guide") ``, `` [checklist.md](checklist.md) ``) —
  это не настоящие ссылки на файлы, а иллюстрация самого синтаксиса в тексте урока. Не чинить —
  так же устроен и оригинал.
- Картинки/GIF в README ведут на `raw.githubusercontent.com` оригинала, не на локальные файлы —
  сами ассеты сюда не копировались (см. выше).
