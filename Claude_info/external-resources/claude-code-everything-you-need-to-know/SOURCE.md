# Источник

Оригинал: https://github.com/wesammustafa/Claude-Code-Everything-You-Need-to-Know

Независимый (не от Anthropic) обучающий гайд по Claude Code — 3 уровня
(beginner/intermediate/advanced), 61 урок с практическими проверками. Лицензия — MIT (см.
`LICENSE` в этой папке).

**Что здесь:**
- `README.ru.md` — полный перевод README оригинала (структура/markdown сохранены).
- `docs-catalog.ru.md` — краткий русский каталог по всем 61 уроку (переведённый заголовок +
  суть в одну строку на каждый). Это не перевод уроков целиком, а карта по ним.

**Чего здесь нет:** сами тексты уроков (`docs/beginner|intermediate|advanced/...`), картинки
(`assets/`), примеры кода (`examples/`), MCP-серверы и т.п. — это осталось в оригинале на
английском, см. ссылку выше. Если понадобится перевод конкретного урока — сказать, какой
именно, переводить всё заранее не стали (61 файл, 5.4МБ — большая часть того объёма вам,
скорее всего, не понадобится).
