# 🤖 Claude Code — AI DevOps-ассистент на сервере

Всё для запуска [Claude Code](https://claude.com/product/claude-code) прямо на своём Linux-сервере
в роли дежурного ИИ-инженера: диагностика на естественном языке, поиск причин инцидентов, починка
под контролем — без необратимых действий без твоего ведома.

---

## 🧭 Навигация

| Раздел | Что внутри |
|---|---|
| 🛡️ **[hardened-install/](hardened-install/README.md)** | Защищённая установка: `settings.json` + хук `guard.sh`, блокирующий необратимые команды (firewall, SSH-локаут, снос томов, утечку секретов) на уровне кода. Для боевого сервера. |
| 🧼 **[clean-install/](clean-install/README.md)** | Установка «из коробки», без хука и урезанных прав — только штатное подтверждение каждой изменяющей команды. Для тестового/расходного сервера или своей настройки `permissions`. |
| 🔄 **[knowledge-transfer.md](knowledge-transfer.md)** | Перенос памяти агента (накопленный контекст, стиль кода, референсные модули) на новый сервер после установки. |
| 📚 **[external-resources/](external-resources/README.md)** | Материалы для изучения Claude Code — от основ до продвинутых паттернов (хуки, субагенты, MCP, плагины, CI). |

---

## 🤔 Какой вариант установки выбрать

| | 🛡️ hardened-install | 🧼 clean-install |
|---|---|---|
| Хук `guard.sh` (жёсткий блок необратимого) | ✅ | ❌ |
| Урезанный `allow`/`deny` под Docker/Remnawave | ✅ | ❌ |
| Мастер настройки (`setup-wizard.sh`) | ✅ | ❌ |
| Подходит для | боевого сервера с реальными данными | теста, расходной ноды, своей конфигурации |

Если не уверен — начинай с **hardened-install**: защита лишняя не бывает, а убрать её при желании
проще, чем добавлять постфактум.
